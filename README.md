## Cara Menjalankan

1. Download / extract folder ini.
2. Buka file `index.html` langsung di browser (double click).
3. Semua halaman terhubung lewat menu navigasi di atas.

## Struktur Folder

```
project-kelompok/
├── index.html      -> Beranda
├── profil.html      -> Profil & cerita usaha
├── galeri.html       -> Galeri produk
├── data.html          -> Daftar menu & harga
└── assets/
    ├── css/style.css
    └── images/
```

## Sumber Gambar

- `hero.jpg` (foto biji pala kering) sudah memakai foto asli.
- `owner.svg` masih berupa **ilustrasi placeholder** buatan sendiri — ganti dengan foto pemilik usaha sebelum dikumpulkan.
- `produk1.jpg` (Manisan Pala Basah), `produk2.jpg` (Manisan Pala Kering), `produk3.jpg` (Sirup Pala), `produk5.jpg` (Selai Pala), `produk6.jpg` (Dodol Pala) sudah memakai foto produk.
- `proses1.jpg` dan `proses2.jpg` (halaman Profil) menampilkan proses produksi oleh ibu-ibu setempat.
  **Catatan:** foto-foto ini diambil dari internet (hasil pencarian produk UMKM pala Bogor) sebagai contoh sementara. Sebelum dikumpulkan, cantumkan sumber aslinya di sini atau ganti dengan foto produk sendiri agar tidak melanggar hak cipta.

Produk Permen Pala belum disertakan di galeri/menu karena belum ada fotonya — tambahkan sendiri kalau diperlukan.

## Teknologi

HTML5 + CSS3 murni. Tidak menggunakan Bootstrap, Tailwind, JavaScript, CMS, atau template siap pakai.
